# বাজার দর (BazarDor)

বাজার দর হলো একটি আধুনিক ওয়েব অ্যাপ্লিকেশন যার মাধ্যমে নিত্যপ্রয়োজনীয় পণ্যের বাজার মূল্য খুব সহজেই এক নজরে দেখে নেওয়া যায়।

## 🚀 Short Description
This project provides a responsive platform to check real-time and estimated daily market prices for various essential goods, featuring seamless navigation and authentication pages.

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS
- JavaScript (ES6+)

## ✨ 5 Key Features of the Project
1. **Dynamic Product Rendering:** Fetches real-time product data and displays items cleanly using responsive cards.
2. **Skeleton Loaders:** Smooth loading animations while fetching API data.
3. **Sorting Functionality:** Easily sort products by price (Low to High / High to Low).
4. **Authentication Pages:** Dedicated Sign-In and Sign-Up pages with responsive forms.
5. **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
